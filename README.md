# 入試問題リファレンスアプリ

入試問題PDFをアップロードすると、大問(「第1問」「大問2」など)の見出しを検出して
問題ごとにページ画像を切り出し、単元・問題数・大学名で検索して参照できるアプリです。

## 構成

- バックエンド: FastAPI (`backend/`)
  - `pdf_processor.py`: PyMuPDFで大問見出しを検出し、該当ページ範囲を画像として切り出す
  - `units.py`: 単元名と同義語・関連キーワードの辞書(簡易分類用)
  - `storage.py`: 問題メタデータをJSONファイルで永続化
  - `main.py`: アップロード・検索・一覧・削除のAPI
- フロントエンド: 素のHTML/CSS/JS (`frontend/`)
- データ: `data/uploads`(元PDF), `data/images`(切り出し画像), `data/index.json`(メタデータ)

## セットアップ

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## 起動

```bash
cd backend
uvicorn main:app --reload
```

ブラウザで http://127.0.0.1:8000 を開きます。

## 使い方

1. 「PDFアップロード」タブで入試問題PDFを選択します(複数可)。
   ファイルごとに大学名・年度・科目を入力できます(任意、空欄でも解析されます)。
2. アップロードすると自動的に大問単位に分割され、ページ画像が生成されます。
   大問見出しが検出できないPDFは1ページ=1問題として扱われます。
3. 「問題を探す」タブで単元名(例: 微分・積分、確率、二次関数など)、問題数、
   大学名(任意)、科目(任意)を指定して検索すると、該当する問題がページ画像付きで表示されます。
4. 「アップロード済み一覧」タブで登録済みPDFの確認・削除ができます。

## 単元の判定方法

`backend/units.py` のキーワード辞書と、切り出した問題テキストとの一致数でスコアリングする
簡易的なキーワードマッチングです。辞書にない単元名を入力した場合は、その文字列自体を
キーワードとして全文検索するため、数学以外の科目(英語・国語・理科・社会など)でも
任意のキーワードで検索できます。辞書は `UNIT_KEYWORDS` に追記することで拡張できます。

## 既知の制約

- 大問見出しの検出は正規表現ベースのため、レイアウトが特殊なPDFでは分割精度が落ちる場合があります。
- 大学名・年度・科目はアップロード時にユーザーが入力する方式です(PDFからの自動抽出は行いません)。
